Secret vault

Encrypted at rest (AES-256-GCM). Plaintext is never stored, listed, or returned — reference a secret anywhere as secret://name. memnos also auto-redacts secret-looking text from remembered messages so credentials can't leak into recall.

CLI reference

Generated from the memnos CLI itself (memnos docs-gen) — always in sync with the installed version. Remote use: set MEMNOS_URL and MEMNOS_TOKEN to point memnos remember/recall at this server from another machine.

LLM provider

memnos never stores your LLM key. It lives in .env (OPENAI_API_KEY). SSO, RBAC, encrypted secret vault and multi-tenant are enterprise features.
