Benchmarks, honestly

The same answers can score
44% or 88%.

AI memory is full of impressive accuracy numbers — 90%, "state of the art," "best in class." Here's the uncomfortable truth: on the exact same answers, a memory benchmark can read anywhere from the low 40s to the high 80s, depending entirely on who grades it and how. This is a vendor-neutral guide to reading those numbers — and how we report ours.

These are real numbers from the same model answering the same questions — only the grading rubric changed. A headline can move 40+ points without the underlying system getting one bit smarter. So when you see a single big number with no rubric attached, you're reading a marketing decision, not a measurement.

Five ways a benchmark number gets inflated

None of these are lying, exactly. They're choices — and each one quietly pushes the number up. Knowing them lets you read any vendor's claim with clear eyes.

1

The model grades itself

Most published scores use an LLM as the judge — and very often it's the same model family that produced the answers. A model grading its own output has a measurable self-preference bias. Ask: who graded this, and was it independent?

2

A lenient rubric

"Mark correct if the answer contains at least one right item." "Dates within two weeks count." "Paraphrases count." Pair that with an answerer told to never say 'I don't know' and dump extra guesses, and the pass rate climbs on its own.

3

A flattering baseline

"90% fewer tokens, 91% faster" sounds huge — until you notice the comparison is against stuffing the entire history into the prompt, the slowest, most expensive option there is. Beating the worst baseline isn't the same as beating the practical alternatives (like plain retrieval).

4

A small, gameable test

Popular memory benchmarks are tiny — on the order of ten conversations and a few thousand questions, some short enough to fit in a modern context window. Small sets are noisy and easy to over-fit, and a couple of categories are known to be ambiguous. Big numbers on small tests deserve scrutiny.

5

No reproducible harness

A single run, no seeds, no variance reported, the judge prompt unpublished, sometimes the rival systems configured by the people they're being compared against. If you can't re-run it and get the same answer, it's a claim, not a result.

✓

The honest version

Independent judge. Published rubric. The full judge band, not one cherry-picked point. A fair baseline. An open harness anyone can re-run. Numbers reported with their caveats. That's the bar — and it's the bar we hold ourselves to below.

Five questions to ask of any memory number

Copy these. Use them on us, too.

Q1

Who graded the answers? A human, a rubric, or an LLM? If an LLM — was it a different provider than the one being scored, or did the model grade itself?

Q2

Where's the rubric? Is the exact judge prompt published? How strict is "correct"? Show me the same answers under a strict and a lenient rubric.

Q3

What's the baseline? Is the "X% better" measured against the worst possible option (full-context stuffing) or against the real alternative you'd actually deploy?

Q4

Can I re-run it? Is the harness open? Are there seeds, multiple runs, and a reported variance — or one lucky run?

Q5

Were the rivals configured fairly? Head-to-head numbers are only meaningful if every system was set up correctly — ideally by a neutral party, not by one of the competitors.

How we report ours

We'd rather publish a credible 58% than an inflated 85%

Here's exactly how memnos measures itself on a standard long-conversation memory benchmark — with every choice above made the honest way.

An independent, cross-provider judge

We have one AI provider grade another provider's answers — never the model grading itself — to strip out self-preference bias. That's the number we lead with.

The whole band, published

We show the same answers under strict, standard and lenient rubrics — so you can see how much the grader moves the number, and pick the one you trust.

An open harness

The evaluation script ships in the repo. Re-run it yourself, swap the judge, change the rubric — and get the same numbers we did.

Honest about the test itself

We don't pretend the benchmark is perfect — it's small and has known quirks. A reproducible, independently-judged number on a flawed test still beats an unverifiable one.
