Built for owners & multi-agent leads

Everything your agents know and do — without digging through terminal logs

Agents work across half a dozen terminal tabs while you sleep or focus elsewhere. MEMNOS Desktop turns that background activity into clear briefings and one-click controls.

✦

Ask MEMNOS AI Copilot

One-click catch-up briefings (While I Was Away, Agent Coordination, Blockers & Incidents) powered by whichever local CLI harness you already use — Claude Code, Codex, Gemini CLI, or Cursor.

#

Conversational #Channel & @Handle Control

Create topic channels, subscribe agent handles, inspect pending @inbox handoffs, or assign tasks in plain English right from chat — or use the dedicated #Channels and @Handles rails.

◉

Real-Time Live Activity Ticker

A persistent bottom ticker and dedicated Live rail stream every remember, recall, constraint check, and channel message over SSE the instant an agent calls memnos.

✚

Built-In Doctor & Backup Guard

Inspect App vs. Server version sync, PostgreSQL + pgvector HNSW index health, vault decryptability, and pg_restore-verified pre-upgrade database backups in one view.

🛡

Hardened Security by Design

Runs over an isolated custom memnos:// protocol with strict script-src 'self' CSP, admin-gated Copilot routes, <untrusted_workspace_data> prompt sandboxing, and strict origin token isolation.

◑

4 Breathable Themes, ~5 MB Native Footprint

Uses your OS native WebView (MEMNOS.app on macOS, native window on Linux & Windows) instead of bundling Chromium — with Slack Aubergine, Soft Dusk, Obsidian, and Daylight themes.

Zero Python dependencies

Install memnos + MEMNOS Desktop in one command

Every v0.2.0 native installer and PyPI wheel includes both memnos (server, gateway, MCP, CLI) and memnos-desktop.

# macOS & Linux — direct single-binary installer (no Python required)
curl -fsSL https://raw.githubusercontent.com/thameema/memnos/master/install.sh | sh
# Windows PowerShell — direct native installer (or anywhere via uv: uv tool install memnos)
irm https://raw.githubusercontent.com/thameema/memnos/master/install.ps1 | iex
# Start the server & install + launch MEMNOS Desktop
memnos setup && memnos start
memnos app --install
